Fungsi/Kegunaan dari Setiap Metric pada Dashboard:

1. CPU Utilization (Line Chart)
   Mengukur persentase penggunaan CPU pada setiap instance VM.
   Berguna untuk memantau beban kerja dan memastikan autoscaling
   bekerja dengan baik saat traffic melonjak (misalnya saat flash sale).

2. Network Bytes Received (Scorecard)
   Mengukur jumlah byte yang diterima oleh instance dari jaringan per detik.
   Berguna untuk memantau volume traffic masuk ke aplikasi e-commerce,
   sehingga tim IT dapat mengidentifikasi lonjakan traffic yang tidak wajar.

3. Disk Read Operations (Stacked Bar Chart)
   Mengukur jumlah operasi baca disk per detik pada setiap instance.
   Berguna untuk memantau performa I/O disk dan mendeteksi bottleneck
   pada storage yang dapat memperlambat waktu respons aplikasi.

4. Network Bytes Sent (Stacked Area Chart)
   Mengukur jumlah byte yang dikirim oleh instance ke jaringan per detik.
   Berguna untuk memantau volume data yang dikirim ke pelanggan,
   membantu mengidentifikasi apakah response time tinggi disebabkan
   oleh bandwidth yang tidak memadai.

Alasan Pemilihan Machine Type, Region, dan Load Balancer Type:

Machine Type: e2-micro
- Dipilih karena merupakan tipe mesin paling hemat biaya untuk workload
  ringan. Sesuai dengan permintaan perusahaan untuk menghemat budget.
- Dengan autoscaling (min 1, max 5 per region), kapasitas akan
  menyesuaikan secara otomatis saat traffic meningkat.

Region: asia-southeast1 (Singapura) dan europe-west1 (Belgia)
- asia-southeast1 dipilih karena merupakan region terdekat dengan basis
  pelanggan terbesar di Asia Tenggara, memberikan latensi rendah.
- europe-west1 dipilih karena merupakan region dengan biaya kompetitif
  di Eropa dan terdekat dengan basis pelanggan Eropa.
- Dua region memenuhi kebutuhan ketersediaan global dan redundansi.

Load Balancer Type: Global External Application Load Balancer (HTTPS)
- Dipilih karena mendukung distribusi traffic secara global ke backend
  di multiple region, sehingga pelanggan diarahkan ke instance terdekat.
- Mendukung protokol HTTPS untuk keamanan data pelanggan e-commerce.
- Terintegrasi dengan Google Cloud CDN dan health check untuk keandalan.
